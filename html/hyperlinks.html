Hyperlinks

To create a hyperlink, use <a> </a> tags.

Inside <a> tags, specify the href attribute to define the link's destination.

For example: <a href="https://www.google.com">Visit Google</a>

Visit Google

Within <a> tags, you can also specify the target attribute to control where the link opens.

For example: <a href="https://www.google.com" target="_blank">Visit Google in a new tab</a>

Visit Google in a new tab

You can also create links to email addresses: <a href="mailto:someone@example.com">Email Someone</a>
