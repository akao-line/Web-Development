Basic HTML

HTML = HyperText Markup Language

-structure of building web pages

To start an html document, you need to use <!DOCTYPE html> declaration followed by the element <html> </html> which is the root element of an HTML page.
The <head> </head> element contains meta-information about the document, such as its title, which is defined using the <title> tag.
The <body> </body> element contains the content of the document, including headings, paragraphs, images, links, and other elements.

Basic Elements:
- <h1> to <h6> - Headings
- <p> - Paragraph
- <br> - Line Break
- <hr> - Horizontal Rule
