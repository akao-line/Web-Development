Basic CSS

CSS = Cascading Style Sheets

-Used to style and layout web pages

There are three ways to use CSS:
-Inline CSS
-Internal CSS
-External CSS

External CSS is defined in a separate .css file and linked to the HTML page. It works the best for maintaining large websites.

Inline: It is written directly inside the HTML element using the style attribute.

Internal: It is written inside the <style> </style>tag in the HTML document.

External: It is defined in a separate .css file and linked to the HTML page. Link by using <link rel="stylesheet" href="styles.css" > inside the HTML document.
Inside the .css file, you can write CSS rules to style the HTML elements. For example:

h1{
color: blue;
font-size: 24px;
}

This is a heading using CSS

body, h1, p can be directly use here in the .css file to style the elements

Html elements can be given an "id" or "class" attribute to target them specifically in the CSS file.

To target an element by its id, declare id="element_id" in the html element and use the # symbol followed by the id name.
To target an element by its class, declare class="element_class" in the html element and use the . symbol followed by the class name.

Example:
-Id
#p1{
color: red;
}

Red

Class:
.element_class{
color: blue;
}

Blue
